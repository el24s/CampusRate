# Campus Rate

Le projet Campus Rate consiste à consulter des endroits ou services du campus et de permettre aux étudiants de laisser leur appréciation.



Commandes d'Initialisation
- npm i 
- npm install typescript --save-dev
- npm i @nestjs/common
- npm i -g @nestjs/cli
- npm install class-validator class-transformer
    documentation
        - npm install @nestjs/swagger@^11.4.7
        

run - backend
- `npm run start`
- `npm run start:dev`

run - frontend
- `npm run dev`


Une documentation interactive est disponible grâce à SwaggerUi:
-   `http://localhost:/3000/api/docs`
